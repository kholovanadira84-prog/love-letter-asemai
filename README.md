# Любовное письмо по QR ❤️

1. Открой `index.html` — письмо уже готово.
2. Загрузите файл на любой статический хостинг (например, GitHub Pages, Netlify или Vercel).
3. После публикации откройте публичную ссылку сайта: QR-код на странице автоматически будет создан с этой ссылкой.
4. Сохраните/распечатайте QR-код и подарите его ей.

Чтобы изменить текст письма, откройте `index.html` и отредактируйте блок `<div class="letter">`.
